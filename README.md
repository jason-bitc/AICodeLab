# 卡瓦重跑酷（微信小游戏原型）

一个基于微信小游戏 Canvas 的跑酷框架，主题素材来自“洛克王国世界”灵感：

- 主角：卡瓦重（当前使用占位绘制）
- 障碍物：矿石、木桩、大树
- 收集物：可口果、魔力果

## 当前已实现

- ✅ 基础游戏循环（`update + render + requestAnimationFrame`）
- ✅ 主角跳跃与重力
- ✅ 障碍物随机生成与碰撞判定（碰撞后游戏结束）
- ✅ 收集物随机生成与拾取判定
- ✅ 资源累计（可口果/魔力果）
- ✅ 开始态/结束态 HUD

## 目录结构

```text
.
├── game.js          # 入口
├── game.json        # 微信小游戏配置
└── js
    └── main.js      # 主要逻辑
```

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择 **小游戏** 项目。
2. 导入当前目录。
3. 点击编译并在模拟器中运行。
